## flow-skill 文件路径契约定稿并落文档

- 文档：`flow-skill/docs/文件路径契约.md`（9 章，与输入输出契约同版本 0.2.0 实现）
- 统一三类基准目录：技能目录 base_dir（instruction）/ Run Workspace（产物）/ data_dir（数据库）
- 定稿决策：
  - workspace 路径书写规范：相对、禁 ..、正斜杠存储，normalize 函数定义期/提交期共用
  - FileOutput 提交核验五条：path 一致性、workspace 内、存在、扩展名、metadata 按 format 分发
  - instruction 经 base_dir 解析为绝对路径存库，保留 instruction_raw；CLI 自动探测 workflow.py 所在目录
  - data_dir 解析链（--data-dir > 环境变量 > default_data_dir > .flow-data 兜底）+ 探针写入（不可写即报错，绝不静默换地方）
  - 注册表每技能一份（workflow.py 旁 .flow-registry.json），run_id → data_dir；续跑注册表是唯一事实源，改绑必须显式 --rebind，--register 收编存量 Run
  - 冲突防护：重复 create-run 拦截、技能指纹（skill_path）防同名共用 data_dir
  - --inputs-file 由包落位到 workspace/inputs/ 并记 inputs_source
  - ctx.resolve / is_within_workspace（含 symlink 逃逸检查）
- 主设计文档 §8 已更新指向新契约；实现清单含 registry.py/paths.py 两个新模块。
